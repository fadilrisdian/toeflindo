Unit 98–99: -ing / -ed adjectives and adjective order

1. Immediate start

Start with one decision right away: choose the adjective that describes the thing, then notice the rule.

The main idea

Use -ing adjectives to describe the person, thing, situation, or experience that causes the feeling: The movie was disappointing.

Use -ed adjectives to describe the person who feels that emotion: We were disappointed.

Quick check: ask yourself, “Is this the cause, or the person feeling it?”

2. Core decision rule

Use the decision model below to sort examples and build confidence.

Decision model

Cause → -ing | Feeling → -ed

Examples: boring lecture / bored students, exciting trip / excited traveller.

Sub-skills to master

  1. Choose -ing for the thing that causes a feeling.
  2. Choose -ed for the person who feels it.
  3. Fix common mix-ups like I am boring vs I am bored.
  4. Order adjectives naturally: opinion before fact, then size, age, colour, origin, material.
  5. Notice fixed patterns such as the first two days and adjectives after be / seem / become.
